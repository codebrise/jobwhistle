# Jobwhistle — Product Roadmap

---

## Phase V1 — Core Release (Current)
- [x] Deterministic HTTP/HTTPS uptime monitoring.
- [x] Cron heartbeat monitoring with secret check-in URLs.
- [x] Idempotent incident lifecycle with 2-check failure confirmation.
- [x] Transactional email alerts via Resend with verified DKIM/SPF.
- [x] Multi-layer SSRF defense engine.
- [x] Public marketing website, legal pages, and technical documentation.
- [x] Developer dashboard with real latency charts and check history.

---

## Phase V1.1 — Team Integrations
- [ ] Telegram Bot integration.
- [ ] Discord webhook embeds.
- [ ] Slack incoming webhooks.
- [ ] ntfy.sh and UnifiedPush support.
- [ ] Custom webhook HMAC signatures.

---

## Phase V1.2 — Advanced Probing
- [ ] Keyword presence/absence assertions in response bodies.
- [ ] SSL certificate expiration alerts (30, 14, 7 days before expiry).
- [ ] Configurable maintenance windows to suppress alerts during deployments.

---

## Phase V2 — Public Status Pages
- [ ] Hosted public status pages on subdomains.
- [ ] Custom domain CNAME support with automatic SSL.
- [ ] Incident communication banner posts.
- [ ] Email subscription for status page updates.

---

## Phase V3 & V4 — Multi-Region & Native Mobile
- [ ] Probing from multiple global regions (North America, Europe, Asia-Pacific).
- [ ] Native Android and iOS applications utilizing pre-designed app icons.
- [ ] Native push notifications.
